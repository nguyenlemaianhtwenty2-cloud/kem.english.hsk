TOEIC Path – bản chạy độc lập
=============================
Đây là toàn bộ trang web (HTML/CSS/JS tĩnh), không cần máy chủ xử lý.

Chạy thử trên máy tính: mở file index.html bằng Chrome/Safari.

Đưa lên mạng để mở bằng một đường link (miễn phí), chọn một trong các cách:
- Netlify: vào app.netlify.com/drop rồi kéo thả cả thư mục này vào.
- GitHub Pages: tạo repo, đẩy toàn bộ file lên, bật Pages ở nhánh main.
- Vercel / Cloudflare Pages: tạo dự án tĩnh từ thư mục này.

Lưu ý khi chạy ngoài Claude:
- Tiến độ lưu trong trình duyệt của từng máy (không đồng bộ giữa các máy, chưa có đăng nhập).
- Giọng đọc dùng giọng có sẵn của trình duyệt.
- Chấm bài dịch dùng cách so khớp từ khoá (không có AI).
- Shadowing: gõ lại câu để kiểm tra (không nhận giọng nói).
